```
docker build .
```

this command use an alternative to image id , use prefix and suffix to make it easy to use, and -t is essential to make it an alternative 
```
docker build -t whydrf/redis:latest .
```

to add some addition commands to the container use this: 
```
docker run -it <image-id> sh
```
for example: 
```
docker run -it whydrf/nodejs sh
```
