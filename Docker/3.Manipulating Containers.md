- **`docker ps`**:
    
    - Lists all **running** Docker containers. It shows container IDs, names, statuses, and the images they're based on.
- **`docker ps --all`** (or `docker ps -a`):
    
    - Lists **all** containers, including stopped ones. It helps you see containers that have exited or failed.
- **`docker create <image-name>`**:
    
    - Creates a new container from the specified image without starting it. This is useful when you want to configure the container before running it. It returns a unique container ID.
- **`docker start -a <image-hash-id>`**:
    
    - Starts an **existing** container (created with `docker create` or previously stopped). The `-a` (attach) flag shows the container's output in your terminal.
- **`docker system prune`**:
    
    - Cleans up your Docker environment by removing **stopped containers**, **dangling images** (unused images), **unused networks**, and **build cache**. This helps free up disk space.
- **`docker logs <container-id>`**:
    
    - Displays the logs of a running or stopped container, showing the standard output and error messages. This is useful for debugging and monitoring application behavior.
- **`docker stop <container-id>`**:
    
    - Displays the logs of a running or stopped container, showing the standard output and error messages. This is useful for debugging and monitoring application behavior.

- - **`docker pull <image-name>`**:
    - Downloads a Docker image from **Docker Hub** (or another registry) to your local system. For example, `docker pull nginx` downloads the latest Nginx image.
- **`docker run <image-name>`**:
    
    - Combines `docker create` and `docker start` into one command. It creates and starts a new container from the specified image. You can add flags like `-d` (detached mode) or `-p` (port mapping).
- **`docker stop <container-id>`**:
    
    - Gracefully stops a running container by sending the **SIGTERM** signal, allowing the container to shut down safely.
- **`docker rm <container-id>`**:
    
    - Deletes a **stopped** container. It’s useful for cleaning up unused containers. You can't remove running containers unless you use the `-f` (force) flag.
- **`docker rmi <image-id>`**:
    
    - Deletes a **Docker image** from your local system. You need to make sure no containers are using that image before removing it.
- **`docker exec -it <container-id> /bin/bash`**:
    
    - Opens an **interactive terminal** inside a running container, allowing you to explore the file system and run commands as if you were inside the container’s environment.
- **`docker compose up`**:
    
    - Starts and runs multi-container applications defined in a `docker-compose.yml` file. It simplifies starting linked containers (like a web server and database).
- **`docker compose down`**:
    
    - Stops and removes containers, networks, and volumes created by `docker-compose up`, cleaning up the environment.
- **`docker inspect <container-id>`**:
    
    - Shows detailed information about a container or image, including network settings, volume mounts, and environment variables.
